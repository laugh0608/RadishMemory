# ADR 0010：阶段 1 桌面手输资料

状态：已接受（2026-11-08）

## 来源与格式

- “New note” 接受可选标题、正文和用户选定的 Text 或 Markdown 格式。显式保存才创建资料，每次新建分配独立的不透明来源绑定及 lineage，即使已有相同正文。手输与粘贴使用同一入口。
- canonical 类型仍为 `SourceArtifact` 和完整的 `SourceFragment`。来源为 `explicit_user_input`，`origin_ref` 只含不透明绑定。System `radishmemory-desktop-text-entry` 保留给应用内直接输入，仅用来区分编辑入口。此入口没有外部文件路径。
- 正文按应用收到的 UTF-8 字节存储，保留空格和换行，拒绝全空白、NUL 和超过 8 MiB 的正文。Markdown 按原文读写。新资料沿用本地应用的权限和外发策略，保存本身不创建已确认记忆，也不触发网络访问。

## 更正与查看

- 手输资料用 “Edit note” 更正当前版本的正文，保留标题、格式、来源绑定、lineage 及治理信息。不同字节新增版本并指向原当前版本；保存与当前版本相同的正文沿用现有幂等规则。文件导入资料继续使用文件更新入口。
- 编辑携带打开时的来源版本 ID。如果读取更新基准时已发生变化，要求刷新并重新打开编辑器。提交仍由现有存储事务校验当前版本；若并发写入已产生同样的字节，现有幂等分支可以返回该版本。
- 搜索沿用现有索引和权限，只召回当前版本。目录和搜索均可进入来源详情，选中当前或历史版本后用 “View original” 读取该版本的正文。历史版本只读，可使用既有精确导出；删除沿用整条 lineage 的本地删除流程。
- 明文库和加密库共用以上规则。草稿留在当前应用会话，取消时丢弃。加密保存失败沿用 worker 持有原请求的重试与放弃流程。存储格式、迁移和密钥模式沿用既有实现。
