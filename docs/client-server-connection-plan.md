# 官方客户端与同步服务器连接规划

状态：产品方向已确认；同步服务与运行时服务器选择尚未交付。

确认日期：2026-10-12（Asia/Shanghai）。

本文面向产品、桌面 / 后续多端客户端、同步与隐私维护者，定义同一官方客户端连接官方端点和用户自部署后端的目标、数据边界与验收。本文不冻结密码算法、线协议、服务端 schema、恢复方案或新的客户端技术栈。

## 产品目标与服务形态

同一平台、同一正式发布渠道的同一个官方客户端安装包，必须在运行时支持“官方同步服务”和“自部署同步服务器”。用户填写并保存兼容服务器地址即可连接，无需修改源码、重新编译、重签名或使用实例专用安装包。该要求适用于已规划的桌面产品及后续获准交付的多端客户端，不由本次规划新增平台实施。

官方端点纳入正式交付目标，域名、开放时间、运营与配额另外确认。官方服务是可选同步目标，不是单机采集、搜索、资料读取、记忆治理或兼容自部署同步的必要依赖。服务未开放或故障时如实显示状态，用户仍可保持单机或选择自部署路径。

官方与自部署均遵守 [ADR 0003](adr/0003-zero-knowledge-sync-first.md) 的首个零知识同步边界：服务端只中继密文对象、加密操作与必要元数据，内容解密、语义索引、ContextPack 和记忆计算留在受信设备。官方托管不获得额外明文权限；可信私有服务器和可信计算节点继续独立后置。

根 LICENSE、试用 / 分发授权与运营条款仍独立确认。本产品目标不直接授予新许可，也不把当前单机实现写成已有同步服务。

## 用户连接与切换

1. 单机资料库始终可打开；用户明确启用同步后选择官方服务或输入自部署地址。
2. 发送凭据或对象前，以无凭据、有界请求验证实例身份、协议 / 能力和传输安全，展示当前服务器归属及零知识信任说明。
3. 为目标同步域显式完成设备注册、授权或恢复；登录某个服务账号不等于拥有资料库解密权。
4. 切换前停止旧服务任务并处理未完成同步与本地写入状态；旧响应和恢复请求不能污染新域。
5. 新目标重新验证授权与兼容性。断线、失败或服务器不可用时继续保留本地资料，不静默回退官方服务或改变信任模式。

实例、资料库与同步域必须可区分。访问凭据、设备授权、密钥封装、远端 cursor、冲突、删除证据和恢复状态按实际实例 / 域绑定；相同邮箱、对象 ID 或服务端返回的标识不足以自动合并资料库或复用授权。

切换地址不是资产迁移或上传许可，不自动把已采集资料、索引、恢复秘密或 ContextPack 发送给新目标。迁移必须单独枚举对象、记忆版本、策略、删除 / 撤销及恢复证据并获得明确用户意图；本地加密 Source Vault 不因服务器选择重新定义其 canonical truth。

## 连接与隐私要求

- 正式远端使用验证有效的 HTTPS；局域网地址与自有 CA 的支持范围另行冻结，不普遍绕过证书校验。
- 发现信息不能任意改变接收方或将旧实例凭据带到另一 origin；重定向、响应上限、超时和未知协议失败必须可测试。
- 状态区分未启用、服务未开放、未授权、离线、证书 / 协议错误、同步中和恢复待处理；不以“地址已保存”表示已同步。
- 官方和自部署使用同一兼容协议范围；版本与能力发现的具体字段、用户 / 域隔离和兼容窗口在阶段 4 实现前确认。
- 同步服务与模型 / RadishMind Gateway 是不同接收方。选择官方同步端点不授权模型外发，也不改变现有 egress policy。
- 旧单机资料库继续离线可用；未来加入同步须显式建立绑定，不把安装升级或首次服务器选择当作自动上传授权。

## 阶段与当前事实

阶段 1 当前仍建设本地 Source Vault 与桌面集成，没有完整同步或官方端点。当前顺位以[当前状态](status/current.md)为准。本次只更新规划，不改变默认桌面正文入口、加密接线、Provider、密钥库、网络或数据库。

连接能力纳入[MVP 阶段 4](mvp-roadmap.md#阶段-4用户自部署同步)，按以下切片评审：

1. 冻结实例 / 资料库 / 同步域身份、地址 / TLS、兼容发现与必要元数据。
2. 冻结设备加入、凭据与密钥封装、恢复、cursor、冲突和删除证据的域绑定。
3. 实现运行时服务器选择、单机 / 同步状态、停止 / 切换及重启恢复。
4. 用同一候选安装包完成独立目标验证，再取得官方与自部署真实服务交付证据；官方运营、用户隔离、安装 / 升级 / 备份恢复分别验收。

## 验收标准

- 同一个未改动安装包选择官方端点或自部署服务，并完成授权、同步、重启、停止和切换；不修改构建参数。
- 官方与自部署路径按实际开放范围分别取得真实目标证据；官方尚未上线可独立验收自部署路径，未验收一侧明确标记未开放。完整双端点交付需两侧证据，两个合成服务不表示官方端点已可运营。
- 服务关闭或官方不可用时，本地采集 / 检索与兼容自部署路径可用，资料、已确认记忆和删除状态不丢失。
- 两个实例 / 同步域的凭据、设备授权、密钥、cursor 与删除 / 恢复证据不能串用；迟到响应与相同对象 ID 的负向场景失败关闭。
- 两类服务的存储、日志、传输载荷都不能获得内容明文、未包装密钥、语义索引或 ContextPack；必要可见元数据按威胁模型枚举。
- 改地址不会自动上传既有资料、迁移资产、授权模型外发或降级为可信服务器模式。
