## 代码与文档复核

- 目录由 controller 保持当前页，调用现有目录读取接口。搜索命中依靠精确版本和片段标识选中页外来源。界面分页仍包含全量读取和内存排序的成本，规模和延迟以 Q04 的独立验证为准。相关说明见[架构](../architecture.md#阶段-1-本地资料库宿主边界)和[资料库规模基线](../evaluation/phase1-local-library-scale.md)。
- SQLite 的默认 v6 修复先只读检查，写事务内重验原始事实与绑定，重建派生行并在提交后复验。README 改为记录已交付的显式修复，宿主 ADR 补齐入口与停止条件。[宿主 ADR](../adr/0007-phase1-local-library-host.md#错误日志与恢复)
- 应用内保存继续使用 `SourceArtifact` 和 `SourceFragment`。更正沿用原 lineage 与现有并发校验。文件选择器继续为文件操作提供一次性授权。手输合同与实现相符，架构和文档索引补充了路由。[手输资料 ADR](../adr/0010-phase1-desktop-text-entry.md)
- 对照可以显示经校验的历史引用，问答只使用重验后仍为当前版本的证据。两者复用片段引用校验。mock 只排列原文摘录，真实模型外发仍按原有权限与外发合同评审。README、架构和路线图已同步这项区分。[宿主 ADR](../adr/0007-phase1-local-library-host.md#本地资料问答原型)
